# WebGuide AI 开发技能筛选

检索与阅读日期：2026-11-13。范围为官方技能目录、原始项目仓库及实际 SKILL.md。初次筛选后，用户已安装 Superpowers，宿主已确认其技能可用；已读取本机 7.0.1 版的使用约定及 Codex 平台适配说明。其他项目保留为候选，尚未安装。

项目目标：做完整产品并探索商业化，课程要求作为工程过程与阶段检查参考。技能用于帮助明确需求、设计系统、实现功能、调试与验证。

## 推荐组合

**优先考虑 Superpowers 作为主开发工作流，配合官方 Playwright 与 GitHub CI 技能；需要更完整的规格管理时再选择 Spec Kit。**需求与架构类技能可作为补充，但一个功能宜有一份权威规格和一个主要执行流程，避免重复维护多套计划。

## Superpowers 中优先关注的技能

- [brainstorming](https://github.com/obra/superpowers/blob/main/skills/brainstorming/SKILL.md)：澄清用户目标并形成设计，原文要求先读取已有上下文，不重问已明确的决定。
- [writing-plans](https://github.com/obra/superpowers/blob/main/skills/writing-plans/SKILL.md)：把确认的规格拆为文件、接口和验证结果明确的任务。
- [systematic-debugging](https://github.com/obra/superpowers/blob/main/skills/systematic-debugging/SKILL.md)：先复现与收集证据，再验证原因和修复。
- [verification-before-completion](https://github.com/obra/superpowers/blob/main/skills/verification-before-completion/SKILL.md)：完成声明需要实际执行结果。
- [test-driven-development](https://github.com/obra/superpowers/blob/main/skills/test-driven-development/SKILL.md)：测试先行。原文约束较严格，采用时应明确任务范围并遵循本项目和用户的既有约束。
- [requesting-code-review](https://github.com/obra/superpowers/blob/main/skills/requesting-code-review/SKILL.md)：提供需求、变更和版本范围进行独立代码检查；不能替代课程要求的成员 Review。

这几项能力适合逐功能推进，例如先对“录制一次并保存为教程”完成规格、实施、检查和演示，再进入下一个功能。用户已有的决定和工程授权应持续保留，避免重复讨论。

## 接入状态与环境

Superpowers：用户已安装，宿主已确认可用，本机技能版本为 7.0.1。后续开发按任务应用相关技能，继续承接本项目已有目标、决定和授权。其余候选尚未安装；选择主流程和补充技能的建议仍适用。

官方技能目录已通过 skill-installer 的列表脚本查询。该脚本的 installed 字段主要检查用户 skills 目录，不能用它判断系统内置或插件技能的全部状态。

Spec Kit 的 [Codex 集成文档](https://github.com/github/spec-kit/blob/main/docs/integrations/codex.md) 写明会安装项目级 `.agents/skills/speckit-<command>/SKILL.md`。后续若选择它，应使用该版本的集成方式，不套用旧文章命令。

Playwright CLI 技能的默认包装脚本采用 shell，并依赖 npx；Windows 下接入时应检查实际脚本运行方式。另一个官方 `playwright-interactive` 候选对 js_repl 及运行环境有特定要求，因此本次没有将其列为首选。浏览器扩展的加载、后台进程、侧边栏及导航场景仍需专门测试，不能只靠普通网页截图覆盖。

## 取舍建议

初期优先采用一套主流程并验证一个功能闭环。Superpowers 与 Spec Kit 的计划、测试和执行环节有重合，本项目可按需要选择其中一套主导，逐步吸收另一套的模板或独立能力。第三方需求/建模技能适合先读、再用一份实际需求试验其产出质量。

最终要落到仓库里的资产是需求、设计决定、接口协议、测试、运行证据和维护中的代码。技能的价值由这些产物的质量和开发过程的改善来验证。
