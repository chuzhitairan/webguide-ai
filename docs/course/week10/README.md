## 阅读与提交顺序

1. [调研报告](调研报告.md)：干系人、业务目标、真实问题、竞品、发现和需求结论。
2. [用户故事](用户故事.md)：14 条初稿及 Given/When/Then，保留原 US 编号。
3. [调研计划](调研计划.md)：已有证据、当前文档核对、后续试用与可选工作包。
4. [发起人体验记录](发起人体验记录.md)：已有原话与操作记录的整理。
5. [访谈提纲与纪要模板](访谈提纲与纪要模板.md)：供成员实际访谈后填写。
6. [课堂讲解稿](课堂讲解稿.md)：8 分钟讲解结构、正文和演练检查。
7. [团队与过程台账](团队与过程台账.md)：成员、报备、主讲、PR 与 AI 使用记录。
8. [仓库配置与提交清单](仓库配置与提交清单.md)：线上建仓、看板、保护、PR 和人的评审。
