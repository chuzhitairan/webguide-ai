# 真实访谈提纲与纪要模板

此文件为执行工具，当前没有已完成访谈。每次实际访谈后复制“纪要”部分成独立文件，再填写事实。

## 开始前说明

“我们在研究网页操作学习中的困难，这不是考核你。我们想了解你最近一次真实经历，可以随时跳过问题或结束。我们默认只做匿名文字记录，不记录账号、密码或私有内容；如需课堂展示或公开摘要，会先征求你的同意。”

分别确认：愿意参与、愿意匿名课堂使用、愿意匿名公开摘要。拒绝公开不影响参与；未经许可的内容保留在成员本地私密位置，不进入 Git 仓库。

## 提纲（15–20 分钟）

1. 最近一次在 GitHub、Figma 或其他网页完成的具体任务是什么？当时已有何种经验、权限和材料？
2. 从哪里开始，第一次卡在哪一步？当时页面出现了什么，你以为接下来会发生什么？
3. 你试过哪些办法？搜索、视频、AI、问人分别在哪一步有帮助或没帮助？方便的话复述一个具体例子。
4. 后来完成了吗？你用什么依据确认？没有完成带来了什么影响？
5. 如果你教过别人：最近一次反复解释的任务是什么？是否制作过教程，改过哪些内容？
6. 在了解真实经历后，再展示“页面高亮＋说明＋结果核对”的文字概念：它对哪一步可能有帮助，哪一步没用？你有哪些顾虑，会在什么范围内接受扩展读取页面？
7. 还有什么是我们问法没覆盖、但对完成任务很重要的？可否回读我们归纳的关键点，确认没有误解？

避免把“你是不是很需要 AI 高亮”作为起点。先问事实，再讨论概念；“觉得可能有用”不记录成已经证明改善效果。
