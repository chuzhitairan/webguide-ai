## 课堂讲解建议

先讲组员第一次使用网页工具时遇到的实际困难。用用例图说明实时引导、本机经验和团队共享三个阶段。演示找导出入口与进入 PR 详情两个任务，说明为什么一个只需高亮，一个要核对实际到达。最后展示一次模型故障后的继续流程，引出性能、安全和可用性的验收条件。

课后在评审 Issue 中记录实际意见和签字。通过后再定稿、附变更记录并发布 SRS v1.0。
