### NAV-US01 · 配置个人模型

作为操作用户，我希望用自己的模型 API 密钥开启引导，以便只安装扩展就能接入可用模型。

NAV-FR01 / NAV-UC01 · [#14](https://github.com/chuzhitairan/webguide-ai/issues/14) · @chuzhitairan

- When 填写 HTTPS API 地址、模型名称和密钥并同意该域名权限。

## 非功能需求

### NAV-US21 · 性能：及时反馈引导进度

作为操作用户，我希望在模型仍在判断时及时看到进展，以便知道系统在工作并能判断是否需要等待。

NAV-NFR01 / NAV-NT01 · [#33](https://github.com/chuzhitairan/webguide-ai/issues/33) · @2454301

- Given 浏览器使用可控模型桩且单次响应延迟 12 秒，目标页已经就绪。
- When 点击开始引导并记录时间。
- Then 1 秒内显示连接或观察状态。单次调用最多等待 15 秒，单轮总等待预算为 45 秒。分别记录页面和模型耗时。

**依据**　[引导循环和失效处理](../../../docs/design/WebGuideAI-导航-Harness-设计.md#52-什么时候继续复核或停下) · [失败后恢复的 Chromium 回归](../../../tests/e2e/guide.spec.ts#L4)

### NAV-US22 · 安全：限制模型所见数据

作为操作用户，我希望让模型只看到本次指路所需的页面证据，以便避免网页里的账户信息和不相关内容进入模型输入。

NAV-NFR02 / NAV-NT02 · [#34](https://github.com/chuzhitairan/webguide-ai/issues/34) · @3377937120

- Given 模拟网页含可识别的测试密码、表单值、网页 Cookie 和提示注入文字，模型地址已授权。
- When 开始引导并检查捕获的合成模型请求、日志和权限。
- Then 正文含目标与裁剪后的观察，测试密码、表单值和 Cookie 不出现在载荷或日志。个人 API 密钥只作为已授权模型域名的请求凭据，网页文字不能触发越权操作。

### NAV-US23 · 可用性：故障后保留目标

作为操作用户，我希望在模型超时或回复无效后继续原任务，以便不用重新定位和填写目标。

NAV-NFR03 / NAV-NT03 · [#35](https://github.com/chuzhitairan/webguide-ai/issues/35) · @chuzhitairan

- Given 同一轮首次模型请求超时，自动重试收到无效回复。
- When 等待侧栏暂停，然后点击继续引导。
- Then 没有后台自行消耗新请求。侧栏保留原目标，按刚更新的页面重新观察，恢复后可正常高亮并收尾。
