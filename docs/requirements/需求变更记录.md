# WebGuide AI 需求变更记录

2026-11-26 · 第 11 周评审材料。[现行 SRS 草稿](WebGuideAI-SRS-v0.3.md) · [需求变更 Issue 模板](../../.github/ISSUE_TEMPLATE/requirement-change.md)

| 编号与时间 | 变化、原因及影响 | 依据与状态 |
| --- | --- | --- |
| DC01 · 11 月 20–22 日 | 从预设步骤转为按自然语言目标实时引导。保留由用户操作的边界，按当前页面判断、补看和高亮。影响课程 SRS 的用户流程、用例边界和验收。 | [实时导航及实现依据](../design/WebGuideAI-导航-Harness-设计.md)。产品方向经组长确认，SRS 定稿待评审。 |
| DC02 · 11 月 23–25 日 | 终点按找到入口、进入界面、设置生效和用户确认分别核对。真实走查发现，同名位置、过期证据和进入详情前均可能误报。 | [真实站点验证](../design/导航Harness-真实站点验证-2026-11-23.md)。原型和回归已记录，相关验收拟纳入 NAV-UC06 至 NAV-UC09。 |
| DC03 · 11 月 25 日 | 组内预览采用各自的模型 API 密钥，由扩展直连。扩展安装后即可配置模型，便于组员独立试用。影响模型接口与密钥边界。 | [工程配置及直连实测](../design/WebGuideAI-工程配置与开发方式-v0.1.md#6-扩展直连与模型配置)。已纳入原型，对应 NAV-FR01 与 NAV-NFR02。 |
| DC04 · 11 月 25–26 日 | 经验分成随包静态候选、本机提炼和共享发布三个阶段。先确认用户收益再安排存储与服务。 | [经验模块设计](../design/WebGuideAI-经验模块设计.md#7-实施顺序)。开关已在原型中，本机提炼与共享权限为后续评审项。 |

基线后的变更先提交 Issue，记录受影响的需求编号、用例、验收和来源。负责人组织评审并记录批准、延期或驳回。通过后在关联 PR 中同步规格、追溯矩阵和验证说明。正式签字及生效版本以实际发布记录为准。[贡献流程](../../CONTRIBUTING.md#需求变更)
