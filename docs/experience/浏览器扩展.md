# 浏览器扩展经验

更新：2026-11-19。以下结论来自局部实验，真实协作场景的集成仍需验证。

- **动作不等于结果。** 用户点过按钮、页面出现成功词或旧流程成功，都不足以证明当前任务完成。采集并关联任务对应的配置、版本和结果；AI 解释，规则判定。Pages 页面曾在已上线时仍显示 “currently being built”，见 [Pages 实验](../../experiments/pages-state-spike/README.md)。
- **失效先撤销，再重新定位。** 页面隐藏、导航、目标变化或引导暂停时及时移除旧高亮；唯一且可见的目标才恢复指示。观察与迟到响应必须绑定任务及当前上下文。依据：[生命周期实验](../../experiments/extension-lifecycle-spike/README.md)、[运行契约](../design/WebGuideAI-运行契约-v0.1.md)。
- **API 能力以实际浏览器为准。** 实测 Edge 157 暴露侧栏开／关事件，关闭侧栏时连接断开触发暂停且蓝框消失；不能沿用“侧栏一定没有关闭事件”的旧说法，也不能把断连直接当成人为关闭的唯一原因。目标版本变化后复核相关行为。
- **页面已有可操作控件就可以指路。** GitHub 的链接已经可用时，浏览器可能还在等待图片等资源。先观察当前文档里的控件，等实际地址变化后再连接新文档。浏览器回归用一个故意延迟的图片覆盖这一情况。[慢资源回归](../../tests/e2e/sidepanel.spec.ts)
- **自动回归使用独立浏览器配置与配套 Chromium。** 普通扩展标签页可自动验证后台、页面连接、高亮、暂停和界面断连。Edge 原生侧栏及权限提示保留专门验证；浏览器安装时按实际使用的 Playwright 版本取配套修订版。依据：[本机自动化预检](../design/WebGuideAI-工程配置与开发方式-v0.1.md#本机验证记录2026-11-19)。
- **实验权限和交互不能直接当正式方案。** 手动点击扩展的 `activeTab` 实验只证明相应路径，不证明跨源新标签页和持续引导。正式权限、SPA 导航、跨标签关联按[工程设计](../design/WebGuideAI-工程配置与开发方式-v0.1.md)处理。
- **先解决关键未知，再停止扩张实验。** 用户已表示手动小验证适量即可；已有证据足以选方案后，把精力转到闭环实现。需要用户操作或截图时给出明确步骤与观察点，不默认接管整个桌面。
