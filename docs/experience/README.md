发现机制：根目录 [AGENTS.md](../../AGENTS.md)要求助手开始任务时读取本索引；[项目首页](../../README.md)和[文档入口](../README.md)也提供链接。入口随仓库提交，后续会话可重新发现，不依赖本次聊天上下文。
